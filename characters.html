ヤマト主要クルー

古

古代進

Susumu Kodai

20歳（第1作）・全シリーズ / 戦闘班長 → 艦長

ヤマトの主人公。兄・古代守の死をきっかけに宇宙へ飛び出す。熱血漢で正義感が強く、時に無謀とも言える行動を取るが、その純粋さがクルーを鼓舞する。森雪への深い愛情も物語の重要な軸となっており、「さらば」では究極の決断を下す。2199では古代守の死の真相を知ることで大きく成長する。

熱血正義感成長愛情
雪

森雪

Yuki Mori

19歳（第1作）・全シリーズ / 生活班長 / 護衛艦長

ヤマト唯一の女性クルー（第1作）。冷静沈着で知性的。古代進への深い愛情を持ちながらも、プロフェッショナルとして任務を全うする。「さらば」では古代の決断を支える重要な役割を担う。2199では設定が大幅に拡張され、謎めいた出自が物語の鍵となる。

冷静知性愛情謎
沖

沖田十三

Juzo Okita

60代・第1作・2199 / ヤマト艦長

ヤマトの艦長。老齢ながら卓越した指揮能力を持つ。冥王星会戦での敗北から病に侵されながらも、人類の希望を背負ってイスカンダルへの旅を指揮する。その死はシリーズ最大の感動シーンの一つ。「この命に代えても、地球を救ってみせる」という信念の人。

威厳責任感犠牲精神信念
島

島大介

Daisuke Shima

20歳（第1作）・全シリーズ / 航海班長

古代の親友にして航海士。冷静な判断力と高い技術を持つ。古代とは対照的に慎重派だが、いざとなれば果敢に行動する。家族思いの一面も持ち、地球に残した家族への思いが彼の行動の原動力となっている。

冷静技術友情家族愛
真

真田志郎

Shiro Sanada

30代・全シリーズ / 技術班長

「こんなこともあろうかと」の名台詞で知られる天才技術者。義手を持つ謎めいた存在。どんな状況でも解決策を見出す頭脳と、深い過去を持つキャラクター。2199では古代守との関係や、ヤマト建造に関わる秘密が明かされる。

天才冷静謎先見性
徳

徳川彦左衛門

Hikozaemon Tokugawa

50代・第1作〜完結編 / 機関長

ヤマトの心臓部・波動エンジンを管理する機関長。温厚で父親的な存在。クルーたちの精神的支柱となる。病に侵されながらも最後まで任務を全うする姿は多くの視聴者の涙を誘った。「ヤマトを頼む」という言葉は名台詞として語り継がれる。

温厚父性忠誠献身
加

加藤三郎

Saburo Kato

20代・第1作〜2 / 戦闘班 / 飛行隊長

コスモタイガー飛行隊の隊長。豪快な性格と高い操縦技術を持つ。古代とは時に対立しながらも深い信頼関係で結ばれている。「さらば」では妻・美雪と幼い息子を残して戦死するという悲劇的な最期を迎える。

豪快勇敢家族愛悲劇
相

相原義一

Yoshikazu Aihara

20代・全シリーズ / 通信士

ヤマトの通信担当。穏やかな性格で、クルーの中でも特に温和な存在。重要な通信を担当し、イスカンダルからのメッセージを最初に受信した人物でもある。

温和誠実技術

敵・関連キャラクター

デ

デスラー

Abelt Dessler

ガミラス帝国 / ガミラス総統

第1作の主要敵役。ガミラス星の独裁者にして天才的戦略家。当初は冷酷な侵略者として描かれるが、後のシリーズでは複雑な内面と誇り高き姿が明かされ、ヤマトの宿命的な好敵手となる。2199では「ガミラス人も生きる場所を求める者たち」という悲劇的な側面が強調される。

カリスマ誇り宿命複雑
ス

スターシャ

Starsha Iscandar

イスカンダル / イスカンダル女王

イスカンダル星の女王。コスモクリーナーDの設計図を地球に送り、ヤマトの旅の目的を作った人物。古代守との悲恋、そして妹サーシャを通じてヤマトとの深い縁を持つ。2199では彼女の秘密と、ガミラスとイスカンダルの関係が詳しく描かれる。

神秘愛犠牲孤独
ズ

ズォーダー大帝

Zordar

白色彗星帝国 / 白色彗星帝国皇帝

「さらば」「ヤマト2」の主要敵役。白色彗星帝国の皇帝。不死身の肉体を持ち、宇宙征服を目指す。テレサとの関係が物語の重要な鍵となる。2202では彼の真の目的と「愛」への歪んだ執着が描かれる。

不死傲慢執着悲劇
テ

テレサ

Teresa

テレザート星 / テレザート星人

「さらば」に登場する謎の存在。宇宙の平和を守るために白色彗星帝国と戦う。古代進たちに助けを求めるメッセージを送り、ヤマトをテレザート星へ導く。その純粋な愛と犠牲の精神は多くのファンの心を打った。

純粋愛犠牲神秘
ド

ドメル将軍

Domel

ガミラス帝国 / ガミラス銀河方面軍司令

「ガミラスのロンメル」と呼ばれる天才的な戦術家。ヤマトを追い詰める強敵として登場するが、その誇り高き戦士としての姿勢は敵ながら尊敬を集める。2199では彼の家族や内面が丁寧に描かれ、より人間的なキャラクターとなった。

天才誇り戦士悲劇
メ

メルダ・ディッツ

Melda Dietz

ガミラス帝国 / ガミラス戦闘機パイロット

2199で新たに登場したキャラクター。ガミラスの女性パイロットで、ヤマトに捕虜として乗艦することになる。彼女を通じて「敵」であるガミラス人の人間性が描かれ、異文化理解のテーマが深められた。
