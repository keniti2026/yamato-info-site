# 宇宙戦艦ヤマト 総合情報サイト

『宇宙戦艦ヤマト』シリーズ（1974年〜）の作品・登場人物・テーマ・音楽・メカニック・歴史をまとめたファンサイトです。ビルド工程を持たない静的HTML/CSS/JSサイトとして構築しています。

## 公開URL

https://keniti2026.github.io/yamato-info-site/

（GitHub Pages で `main` ブランチ直下 `/` を公開設定にしています）

## ローカルでの確認方法

Python が入っていれば、リポジトリのルートで以下を実行してください。

```
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開くと確認できます。

## ページ構成

| ファイル | ページ内容 |
|---|---|
| `index.html` | トップページ |
| `works.html` | 作品一覧（全シリーズ・年表） |
| `characters.html` | 登場人物（ヤマトクルー／敵・関連キャラクター） |
| `themes.html` | テーマ・ジャンル解説 |
| `music.html` | 音楽（主題歌・音楽スタッフ・動画リンク） |
| `mechanics.html` | メカニック（波動砲・波動エンジン等） |
| `history.html` | 歴史・文化的影響（年表） |
| `links.html` | 外部リンク集 |
| `yamato2199.html` | 「宇宙戦艦ヤマト2199」特設ページ |
| `rebel3199.html` | 「ヤマトよ永遠に REBEL3199」特設ページ |

共通ファイル:

- `style.css` — 全ページ共通のスタイル（ダークテーマ・レスポンシブ対応）
- `script.js` — ナビゲーションのアクティブ表示・モバイルメニュー・ページ内タブ切替

## 制作メモ

- 実在の画像アセットは使用せず、CSSのグラデーション・装飾で宇宙的な雰囲気を表現しています。
- 各ページ末尾の「還暦ブロガー、健一とYuriのレビューワールド」への外部リンク、および各話レビュー記事（1974年版：ameblo.jp／2199・REBEL3199・ヤマトⅢ：anime-station.org「昭和親父が語る宇宙戦艦ヤマト」）へのリンクは実際のURLを使用しています。
- 2026年7月時点で、`yamato2199.html` に「宇宙戦艦ヤマト2199」各話レビュー（第1話〜第6話、以降順次更新）、`rebel3199.html` に第六章レビュー、`works.html` に「宇宙戦艦ヤマトⅢ」全話レビュー総合インデックスへのリンクを追加しました。
